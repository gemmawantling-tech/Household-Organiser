Household Organiser PWA

Upload the contents of this folder to an HTTPS website, keeping index.html, manifest.webmanifest, sw.js and the icons together.

For GitHub Pages: create a repository, upload these files to its root, then enable Pages in Settings > Pages > Deploy from branch > main / root. Visit the resulting https://...github.io/.../ address in Chrome on Android and choose Install app or Add to Home screen.

Important: data saved in the old downloaded HTML file will NOT automatically move to the hosted app. Export backup from the old app, then import that JSON backup in the hosted app. Data is stored locally in your browser; keep backups.
